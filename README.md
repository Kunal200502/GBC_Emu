# GBC_Emu
A GameBoy Color emulator in C++
Uses SDL2 library for rendering
Passes all blargg's cpu tests



## Usage
### To Build 
Create a build folder 
In the build folder -
```
cmake ../src/
cmake --build .
```

### To Exectute-
```
./GBC_emu path_to_rom_file
```
